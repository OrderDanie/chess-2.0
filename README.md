# chess-2.0
as if chess 1 wasnt enough
What if chess,was a tbs tactical war game? Yeaaaa that’s chess 2
Chess 2 is a turn-based strategy game that combines chess with 4X systems
You capture territory, build farms, grow your economy, spawn units, and fight for control of the map. It is not just about moving pieces well. You also need to expand, defend key areas, manage resources, and deal with diplomacy
The game will have both singleplayer and multiplayer, with matches built around map control, army management, and long-term decision making
